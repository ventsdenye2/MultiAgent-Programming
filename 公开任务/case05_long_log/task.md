# 任务：测试大面积失败，定位根因并修复

## 背景

`stats.py` 是一个数据统计管线，提供均值、中位数、方差、标准分数、滑动平均、离群点剔除和批处理汇总。

## 现象

在仓库根目录运行 `python -m pytest -q`，会出现大量测试失败。仓库还附带一个对拍脚本 `run_checks.py`（把 `stats.py` 的输出与内置参考实现逐批比对），运行 `python run_checks.py` 会打印很长的差异报告。注意：不一致虽多，根因只有一个。逐条差异去改实现是走不通的，找到那个共同的根因。

## 要求

1. 定位唯一的根因并修复，使全部测试通过。
2. 只修改 `stats.py`，不得修改任何测试文件。
3. 修复后再次运行完整测试确认全绿。
4. 保留既有函数的行为：统计函数不修改传入列表，`median([])` 仍抛出 `ValueError`。

## 执行与验证要求

1. 修改前，在工作仓库根目录运行完整 `python -m pytest -q`，保留失败输出。
2. 修改任何源文件前，运行 `python run_checks.py`，保留至少12000字符的完整失败输出。
3. 每次发给模型的消息，其 `content` 字符数之和不超过16000。对长输出采用裁剪、历史删除或摘要，记录采用的方法及处理前后信息；完整原输出仍须保留在日志中。
4. 修改后再次运行完整 `python -m pytest -q`，确保全部测试通过；再运行 `python run_checks.py`，退出码须为0。不得用 -k 筛选或只运行个别测试，保留两个命令的完整输出。
