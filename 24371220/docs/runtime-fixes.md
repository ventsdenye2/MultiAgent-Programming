# 首轮真实评测后的运行时修复

修复前回退点：`f447a93`，包含 v2 源码、测试、文档、首轮真实请求与评分记录。重复提交副本、课程源码工作目录与论文副本留在本地；密钥文件在 Git 仓库和提交目录之外。历史评测记录保持原样。

## 已修复

1. **PDF 跨轮校验错误。** `current_hash()` 在校验安全路径之后，按原始字节分块计算 SHA-256，不再复用拒绝二进制的文本读取函数。文本读取限制保持不变。跨轮引用 PDF 可以继续执行；PDF 已变更时，旧变量仍会被标记过期并拒绝使用。
2. **打印额度跨轮累计。** 每个代码块开始时重置打印长度和截断标志，保留 namespace。上一轮超过20,000字符不再导致下一轮输出为空；同一轮多次打印仍共用该额度。
3. **增量赋值报错与配额。** 修复 `ast.walk` 迭代器相加引发的异常。`+=`、`*=`、`**=` 等沿用普通二元运算的重复扩容、幂运算和容器大小上限，并继续追踪来源依赖。
4. **错误反馈的可操作性。** 对真实评测中出现的 `.get()` 与工具位置参数调用，错误消息给出字典索引和命名参数示例，系统提示明确字典访问方式。没有放开属性调用或新增不受限 Python 执行能力。

进一步核对发现，源码题第17–19轮的错误反馈确实进入下一轮请求。因此这次没有修改 ContextBuilder，也不把“错误被旧证据挤出上下文”视为本轮已证实的原因。更清楚的错误提示能否降低真实模型的重复错误，仍需之后验证。
