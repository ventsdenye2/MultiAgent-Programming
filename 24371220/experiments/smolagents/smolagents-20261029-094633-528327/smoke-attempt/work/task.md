# 任务：修复折扣计算缺陷

## 背景

`calc.py` 是一个价格计算模块，提供含税价、折扣、合计和 AA 分账四个函数。

## 现象

在仓库根目录运行 `python -m pytest -q`，折扣计算及相关边界测试失败：打八折后 200 元算成了 1.6 元。含税价、合计和 AA 分账的既有测试用于检查回归。

## 要求

1. 定位并修复缺陷，使全部测试通过。
2. 只修改 `calc.py`，不得修改任何测试文件。
3. 修复后再次运行测试确认全绿。

## 执行与验证要求

1. 修改前，在工作仓库根目录运行完整 `python -m pytest -q`，保留失败输出。
2. 修改后再次运行同一命令，确保全部测试通过，并保留完整输出。不得用 -k 筛选或只运行个别测试。
