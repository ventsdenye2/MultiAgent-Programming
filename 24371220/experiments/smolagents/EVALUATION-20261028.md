## 失败轨迹和原因

五次响应均成功返回，`finish_reason=stop`，没有网络错误、空响应或输出截断。第 3 次请求耗时约 130.31 秒，低于 210 秒等待上限；本次直接退出原因是本地上下文构造错误：

```text
ValueError: CONTEXT_FIXED_OVERFLOW: task, tools and recent feedback exceed budget
```

1. Agent 建立计划，运行完整基线测试，然后调用 `read_file` 完整读取 `calc.py`。
2. 文件只有 **396 字符**，但第 4、5 次请求的证据选择均将其放入 deferred。实际发出的五个请求中，既没有该文件全文，也没有缺陷行 `return price * discount / 100`；`context_exposure` 始终为空。
3. `_recent()` 先占用预算，并将执行器输出中的原文替换为单独证据引用；后续证据选择没有为这份必需源码预留空间。模型因此重新读取和打印，但这些原文仍未到达下一次实际请求。
4. 第六轮达到两次无进展判断，`build()` 把最近工具结果再次放进固定状态区。即使压缩最近反馈，固定内容仍无法装入基础题的预算，错误发生在发送第六个请求之前。

这是自研上下文选择的失败，当前记录不支持把它归因为模型不会修复该缺陷。官方内核和解释器已执行前五轮动作；后续阻断发生在项目的记忆发送视图钩子中。
