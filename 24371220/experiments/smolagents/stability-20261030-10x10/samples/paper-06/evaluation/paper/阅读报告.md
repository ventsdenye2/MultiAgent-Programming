# 论文阅读报告

本文综述 agentic LLM，即能够推理、行动并与环境或他人交互的大语言模型。作者按 reason、act、interact 三类组织文献：推理部分讨论 CoT、自洽性、思维树/思维图与推理专用模型；行动部分讨论工具使用、具身与机器人行动、代码生成；交互部分讨论多智能体协作与人机社会模拟。三类能力层层递进并构成良性循环：推理支撑行动，行动与交互支撑社会模拟，模拟结果又能回流为训练数据微调模型。文章最后给出训练数据、幻觉、agent 行为、自反思与安全等研究议程。

## overview

作者把 agentic 能力分为 reason（推理）、act（行动）与 interact（交互）三类，并指出它们分别对应符号 AI、机器人/自主系统与多智能体建模三个研究传统。三者不是并列堆叠而是相互支撑：推理能力让模型能规划并调用工具去行动，行动与交互支撑社会模拟，模拟产生的数据又可微调模型，形成论文图 1 的良性循环。文献先在 Google Scholar 检索 Agentic LLM，再用滚雪球方式补充被引却未纳入的工作，只保留基于 LLM 的方法，且以 2024 年工作为主。

## reasoning

CoT 用逐步推理把难题分解为中间步骤，是后续方法的基础。Self Consistency 采样多条推理路径，再以多数投票选出最一致的答案，属于集成式方法，明显提升 CoT 表现，也是 o1/o3 等推理模型的思想来源。Tree of Thoughts 引入外部搜索控制器，配合生成与评估提示进行回溯，论文描述了广度优先与深度优先两种控制器；Graph of Thoughts 进一步把思维组织成图结构。局限在于路径评估常依赖模型自身，可能放大幻觉。

联系自己的 agent：我的 agent 目前是单路径直出报告，没有多路径采样投票，也没有搜索式规划。可对同一批页面采样多次并投票，或对答案候选做广度优先扩展与评估剪枝。

```json

  "tot_search": [
    "breadth_first",
    "depth_first"
  ]
}
```

- self_consistency_selection，PDF 第 10 页：Self Consistency is an ensemble approach that samples diverse reasoning paths, evaluates them, and selects the most consistent answer using majority voting.

- tot_search，PDF 第 13 页：The paper describes both a breadth-first and a depth-first controller.

## tool_use

行动主题把工具使用视为 agent 落地的核心。Toolformer 让模型自学何时调用哪个 API、如何填写参数、如何利用返回结果，测试了计算器、问答系统、搜索引擎、翻译系统与日历五类工具。工具检索与规划形成 planner–caller–summarizer 的多模型框架，ToolBench 提供 16,464 个 RapidAPI 接口，作为大规模工具学习与评测的基础。具身方向涵盖 SayCan、Inner Monologue 与视觉-语言-行动模型。局限是 API 频繁变动，调用错误会沿链条传播。

## multi_agent

多智能体主题区分协作与竞争。CAMEL 用 inception prompting 与角色描述让两个模型保持身份，无需持续人工提示即可合作，并通过对话把复杂问题拆成可管理步骤；此外还有创建者-批评者、宪法 AI、多智能体辩论与带裁判的 MAD 等模式。社会模拟方面，Generative Agents 用 100 名人类评估者判断行为是否可信，完整架构表现最好，但仍出现幻觉与反复行为；Sotopia、GovSim 等提供评测环境。局限是成本高、易角色漂移与错误放大。

## outlook

结论把未来工作整理为 Table 4 的五个议题：Training Data、Hallucination、Agent Behavior、Self Reflection 与 Safety，分别关注用推理数据与稳定 RL 训练模型、自我验证与机制可解释性、可扩展的角色扮演与行为建模、模型内自反思与元认知、以及责任、隐私与公平等安全治理。作者强调各类能力共享基础：机器人与工具使用依赖有据的检索增强，社会交互依赖自我反思，而所有类别都受益于推理与自我验证。
