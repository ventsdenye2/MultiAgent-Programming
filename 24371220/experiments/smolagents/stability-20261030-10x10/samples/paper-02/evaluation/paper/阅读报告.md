# 论文阅读报告

这是一篇关于 Agentic LLM 的综述（arXiv:2503.23037v3）。作者把 agentic LLM 定义为能以自然语言接收输入、推理决策并自主行动以达成目标的系统，并把相关能力分为 reasoning、acting、interacting 三类，三者层层递进并构成互相促进的良性循环。文献先用 Google Scholar 检索、再用 snowballing 扩展。正文分别讨论多步推理与自我反思、检索增强、工具使用与规划、角色扮演式多智能体与社会模拟，最后在 Outlook 中给出训练数据、幻觉、agent 行为、自我反思与安全等研究议题，并指出三类能力共同依赖推理与自我验证两种基础能力。

## overview

分类框架按能力把工作组织为 reasoning（多步推理、自我反思、检索增强）、acting（工具使用与规划）、interacting（角色扮演对话、多智能体协作与社会模拟）三部分，三者环环相扣：推理技术支持助手的行动，行动与交互实验产生的结果又可回流为训练数据。文献组织上作者以 Google Scholar 检索加 snowballing 扩展得到论文集合，并只收录基于 LLM 的方法、排除不含 LLM 的多智能体工作，以保证主题聚焦。局限是覆盖面偏向 2024—2025 年的近期工作，部分引文仍是未经同行评审的预印本。

## reasoning

推理部分以 Chain of Thought 为起点：让模型显式写出中间步骤。Self Consistency 在其上采样多条推理路径，用多数投票等一致性规则确定最终答案，从而降低单条路径的错误。Tree of Thoughts 把推理组织成可搜索的树，用广度优先与深度优先两种控制器探索中间状态，并允许回溯。此外还有 Program of Thought 等借助形式语言（代码、解释器）的做法，以及自我反思与检索增强两条互补路线；前者让模型检查并修正自身输出，后者在推理前补充外部知识。

联系自己的 agent：我的 agent 目前是单条链式流程：读页面→记笔记→写报告，没有对同一问题采样多条路径再投票；可以在关键结论（如工具数量、评估者人数）上增加一次独立复核路径，只在两条路径一致时才写入报告，这相当于简化版的 Self Consistency。

## tool_use

行动能力部分强调工具调用：Toolformer 以自监督方式学习何时调用哪个 API、传什么参数、以及如何把返回结果并入后续预测，原文测试了计算器、问答系统、搜索引擎、翻译系统与日历五类工具。ToolBench 收录了来自 RapidAPI 的 16,464 个 API，为工具选择提供了大规模数据。真正的难点不只是调用，而是选对工具并对结果做摘要，因此出现 planner–caller–summarizer 的多模型分工；后续工作把工具范围扩展到更大规模，并涉及工具检索与参数生成。

联系自己的 agent：我的 agent 已有 command_result 形态的工具层（read_pdf.py、read_file、run_command），工具的输入参数与输出都记录成可复用事件；不足是工具由固定脚本流程选择，没有“先判断该用哪个工具、再总结结果”的 planner 环节，未来可把选工具与结果摘要拆成两步提示。

## multi_agent

交互能力部分先讲角色扮演式协作：CAMEL 用 inception prompting 与角色描述让两个 LLM 分别扮演 assistant 与 user 保持身份并共同推进任务，对话失控时还会引入 critic agent 维持建设性。随后扩展到社会模拟：Generative Agents 由记忆、计划与反思模块驱动大量 agent 的日常行为，其行为可信度由 100 名人类评估者按记忆、计划、应对意外与反思四类排序打分，并比较了多种架构；还有模拟上千人访谈的研究，说明多智能体实验已成为收集训练数据的来源。

## outlook

Outlook 用一张表给出研究议程：Training Data（用推理期数据微调、收敛稳定的强化学习、语音等多模态信号）、Hallucination（自我验证、机制可解释性、开放世界模型探索）、Agent Behavior（可扩展的仿真基础设施、角色扮演、把推理蒸馏到小模型）、Self reflection（模型内自我反思与元推理、元认知与人格、自动化科学发现）、Safety（助手的责任与隐私公平等）。结论指出三类能力都受益于 reasoning 与 self-verification，并强调 acting 与 interacting 可为预训练和微调生成训练数据，形成循环。
