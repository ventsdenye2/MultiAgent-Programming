# 论文阅读报告

本文综述 agentic LLM，即能推理、行动并与环境交互的大语言模型。作者把能力分为 reasoning、acting、interacting 三类，分别对应符号 AI、机器人/自治系统与连接主义/多智能体三大传统；文献先用 Google Scholar 检索，再用 snowballing 扩展。正文按推理（CoT、自洽、思维树、自我反思与强化学习）、行动（工具调用、具身与 GUI 操作、安全）、交互（多智能体协作与社会模拟）组织，并以研究议程与三类能力互补的结论收尾。

## overview

论文把 agent 能力分为 reasoning、acting、interacting 三类，层层递进：推理为决策提供基础，行动把决策落到工具与环境，交互则涉及多个 agent 及人类社会。分类与传统符号 AI、机器人/自治系统、连接主义/多智能体研究相对应。文献选取先用 Google Scholar 检索，再以 snowballing 补充被引但未收录的工作，只保留基于 LLM 的方法，少量非 agentic 的 LLM 工作仅作背景。

## reasoning

推理部分从提示工程到结构化搜索：Chain of Thought 让模型逐步推理，Self Consistency 采样多条推理路径并通过多数投票选出最一致的答案，Tree of Thoughts 用外部控制算法调用模型遍历推理步骤树，路径走完后回溯尝试备选路径，论文给出广度优先与深度优先两种控制器。自我反思方向借 actor/evaluator/reflector 提示迭代改进，外部搜索生成的数据还可用于微调，把搜索能力内化到模型。

联系自己的 agent：我的 agent 目前是单条生成路径，没有自洽投票；可对关键抽取任务采样多条路径并用多数投票定稿，也可为证据比对加一层外部树搜索式的回溯重试。

- self_consistency_selection，PDF 第 10 页：Self Consistency is an ensemble approach that samples diverse reasoning paths, evaluates them, and selects the most consistent answer using majority voting.

- tot_search，PDF 第 13 页：The paper describes both a breadth-first and a depth-first controller.

## tool_use

行动主题围绕工具调用与具身操作。Toolformer 自训练决定调用哪个 API、何时调用、传什么参数并把结果并入预测；ToolBench 以大规模 REST API 数据集支撑规划与调用分离的框架（planner/caller/summarizer）。进一步工作涉及工具文档检索、屏幕 GUI 解析、agent 互操作协议，以及提示注入等安全问题，强调要把安全约束嵌入推理与规划流程。

联系自己的 agent：我的 agent 已把 read_pdf.py、pytest 等封装成命令行工具，由模型决定何时调用；不足是没有工具文档检索与调用结果校验；未来可加工具说明检索、参数自检与失败重试。

## multi_agent

多智能体部分比较协作与模拟两条路线：ChatEval 用多角色辩论改进评估，AutoGen 以对话为编程范式，AgentVerse 分招募、协作决策、执行与评估四阶段；CAMEL 用 inception prompting 让角色保持身份并合作。Generative Agents 在小镇中模拟 25 个 agent，具备记忆、反思与计划，其可信度由人类评估者排序打分。后续工作用大规模访谈数据构建 agent 复现人类态度。

## outlook
