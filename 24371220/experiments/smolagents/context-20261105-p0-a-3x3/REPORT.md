## 可定位的问题

1. **输出协议不匹配仍存在。** 源码基线 R5/7/9/10、源码 static R10、论文 static R24/26/35/36 共 9 次 AgentParsingError，均是 DSML 输出未被 Python 代码块解析器接受。原始响应保留；没有转换或修写响应。
2. **源码收尾存在独立失败路径。** baseline R19 已改完并通过 pytest，随后变量名 log 与解释器已有工具冲突；R20 再测通过后调用不允许的 git diff，未到 final_answer。static R18 同样调用被禁用的 git diff --stat，但 R19 修复后完成末改、末测和结束。工具错误及其外层 AgentExecutionError 是同一失败的两层事件，不重复当作两个独立故障。
3. **论文送达不等于成果完成。** static/paper 有 task_status 12 次、recall 14 次、read_pdf 9 次、write_note 5 次调用，未调用保存答案或提交报告。R7 recall 引用了缺失或失效 id；R16 使用未导入的 json；R31 将笔记写成相邻字符串拼接，被连续原文要求拒绝。不能据此把全部回看判定为无用；逐请求正文可供进一步判断。

这些是观测到的路径，不是已完成的根因归因。本次未进一步改协议、上下文算法或课程门槛。后续方向由用户分析后决定。
