# 论文阅读报告

本文综述 agentic LLM：以 LLM 为核心，能推理决策、能通过工具或机器人对外部世界行动、并能在多智能体社会环境中交互的系统。作者把能力划分为 reasoning、acting、interacting 三类，形成论文三大部分：推理（思维链、自洽性、思维树、规划与学习）、行动（记忆、检索增强、工具调用与具身机器人）、交互（多智能体协作、角色扮演与社会涌现行为）。文献先用 Google Scholar 检索，再用雪球法扩展。文章还讨论评估、安全与开放研究议程，并指出行动与交互产生的数据可反哺预训练与微调，形成持续改进的循环。

## overview

本篇把 agentic LLM 的能力分成 reasoning、acting、interacting 三类，并视为相互补充的层次：推理是基础技术，工具使用与机器人交互建立在有据检索增强之上，社会交互（如心理理论）建立在自我反思之上，而三类都受益于推理与自我验证。文献组织方面，作者最初用 Google Scholar 以 Agentic LLM 检索，再用雪球法补充被引却未纳入的文献，且只收录基于 LLM 的 agent 工作。全文按“推理—行动—交互”展开，末尾给出研究议程。

## reasoning

推理主题从提示式方法讲到搜索与学习：Self Consistency 采样多条不同推理路径，评估后按多数投票选出最终答案，因此代价是多次采样；Tree of Thoughts 把推理组织成思维树，由生成提示、评估提示加外部搜索算法组成，作者介绍广度优先与深度优先两种控制器，可以回溯修正中间步骤，但搜索开销较大。规划部分讨论任务分解与计划生成，学习部分讨论用推理数据微调与强化学习，局限是自我验证与幻觉仍难解决。

联系自己的 agent：自己的 agent 已用“先分页读取、再写笔记、最后归并”的分解方式，相当于一次浅层思维树；目前没有分支评估，也没有对多个候选答案投票。可尝试对关键问题生成多条抽取路径并用多数投票或自我验证筛掉证据不足的候选。

```json

  "tot_search": [
    "breadth_first_search",
    "depth_first_search"
  ]
}
```

- self_consistency_selection，PDF 第 10 页：Self Consistency is an ensemble approach that samples diverse reasoning paths, evaluates them, and selects the most consistent answer using majority voting.

- tot_search，PDF 第 13 页：The paper describes both a breadth-first and a depth-first controller.

## tool_use

工具使用主题讨论模型如何发现、调用并整合外部 API：Toolformer 以自监督方式让模型标注哪些位置调用哪个 API、传什么参数、结果如何并入后续 token 预测，文中测试了计算器、问答系统、搜索引擎、翻译系统与日历五种工具。数据集方面，ToolBench 收录 16,464 个来自 RapidAPI 的公开 REST API，规模带来文档质量与检索难题。局限是工具调用的可靠性、错误传播与幻觉，以及真实环境中动作的后果。

联系自己的 agent：自己的 agent 已有命令工具调用 read_pdf.py 并把 JSON 结果写入记录，属于最简单的工具调用形态；不足是工具参数固定、失败后需人工改错，没有自动重试或工具选择。未来可加参数校验与失败回退，把工具返回的完整 stdout 存档再选页送入模型。

## multi_agent

多智能体主题把 agent 放进社会场景：CAMEL 用 inception prompt 给 assistant 与 user 两个角色一个初始构想，使它们保持身份并通过互发消息协作完成任务，还引入 critic agent 保证沟通建设性，使 HumanEval 从 30% 提升到约 50%。Generative Agents 在模拟小镇中放置约 25 个 agent，架构含记忆、规划与反思，可信度由 100 名人类评估者排序检验。局限是角色漂移、幻觉与意外行为，评估成本高。

联系自己的 agent：自己的 agent 目前只有单线程单一角色，尚未实现多智能体协作；已有的分页选择与笔记机制可复用作“读取者”与“归纳者”两个角色的共享状态。未来可尝试让一个角色抽取证据、另一个角色核对页码与引文，再合并成报告。

## outlook

Table 4 给出五个研究议题：Training Data（推理时数据微调、稳定强化学习、VLA 与多模态）、Hallucination（自我验证、机制可解释性、开放世界模型）、Agent Behavior（可扩展模拟、角色扮演、蒸馏小模型、涌现行为）、Self reflection（模型内自反思与元推理、元认知与人格、自动化科学发现）、Safety（责任与问责、隐私与公平、更广应用）。结论强调三类能力互补，共同受益于推理与自我验证，行动与交互的数据又反哺训练。
